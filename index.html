Your privacy shield

  • Files never upload. This page is blocked from talking to any server.
  • No accounts, cookies or trackers.
  • Photo location and camera details are dropped when pictures are re-drawn.
  • Spreadsheet exports are neutralised against formula tricks.
  • Nothing is rendered as raw HTML, so odd file names can’t run code.
  • Oversized or unreadable files are politely refused.

Honest note: no website can promise absolute security, but your files never leave this tab, which removes the biggest risks.
